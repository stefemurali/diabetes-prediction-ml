# Diabetes Prediction Using Machine Learning

## Project Description
This project predicts whether a person is likely to have diabetes using machine learning techniques.

## Objective
To develop a machine learning model that predicts diabetes based on medical health attributes.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Algorithm
Logistic Regression

## Dataset
Pima Indians Diabetes Dataset

## Input Features
- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

## Project Outcome
The model predicts whether a person is likely to have diabetes based on the given input features.
